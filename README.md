# Lash Glow AS – versión sin carpeta

Esta versión no usa la carpeta `fotos`. Son 4 archivos sueltos que van en la raíz del repositorio:

```
index.html
trabajo-1.jpg
trabajo-2.jpg
trabajo-3.jpg
```

## Cómo subirlos a GitHub

1. Entrá al repositorio del sitio.
2. Tocá **Add file → Upload files**.
3. Seleccioná los 4 archivos juntos (con Ctrl o Shift, o arrastrándolos).
4. Tocá **Commit changes**.

No hace falta crear ninguna carpeta. El `index.html` nuevo ya busca las fotos por nombre en la misma carpeta donde está él.

> Si el repositorio ya tenía una carpeta `fotos`, podés dejarla o borrarla; esta versión no la usa.
